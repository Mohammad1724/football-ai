# تشخیص اتصال API-Football — نسخه ۰٫۳٫۲

- دریافت فهرست لیگ API-Football اکنون ابتدا `/status` را با کلید مستقیم API-Sports بررسی می‌کند؛ فهرست ثابت لیگ‌ها دیگر به‌تنهایی موفقیت اتصال را اعلام نمی‌کند.
- پاسخ شیء وضعیت حساب، فعال‌بودن اشتراک و مصرف/حد روزانه اعتبارسنجی می‌شود. تأیید حساب به معنی تأیید پوشش فصل یا نتیجه زنده نیست.
- خطاهای JSON سرویس به کلید نامعتبر، سهمیه روزانه، محدودیت نرخ، محدودیت پلن و خطای عمومی تفکیک می‌شوند. خطای ناشناخته دیگر به اشتباه «کلید نامعتبر» نیست. HTTP 403 نیز از 401 جدا شد.
- پیام‌های فارسی و انگلیسی راهنمای متناسب دارند. بدنه خطای سرویس در متن خطا نگهداری یا نمایش داده نمی‌شود تا کلید یا اطلاعات حساب احتمالی افشا نشود.
- ذخیره کلید در صفحه منابع، همان منبع را بررسی می‌کند، نه منبع فعال قبلی؛ تنها پس از موفقیت آن را فعال می‌کند.
- در منابع داده، با انتخاب API-Football دکمه «آزمایش دسترسی: دو لیگ، ۷ روز آینده» اضافه شد. ابتدا وضعیت حساب و بعد بازی‌های لیگ برتر انگلیس و لالیگا بررسی می‌شود. fallback به CSV برای این آزمایش خاموش است تا موفقیت CSV با موفقیت API اشتباه نشود.
- آزمایش انتخاب لیگ‌های قبلی را تغییر نمی‌دهد. پیش‌فرض API در نبود انتخاب معتبر دو لیگ است. خطاهای حساب/سهمیه/پلن ادامه حلقه لیگ‌ها را متوقف می‌کنند.
- خطاهای fallback حفظ می‌شوند و خطای قابل‌فهم در فهرست بازی‌ها و داشبورد نمایش داده می‌شود؛ بررسی حساب به‌تنهایی زمان آخرین همگام‌سازی بازی‌ها را تازه نمی‌کند.

شش تست تشخیص و اتصال HTTP محلی با MockWebServer اضافه شده است. این تست‌ها کلید واقعی و سرویس واقعی کاربر را استفاده نمی‌کنند. پاسخ حساب و پوشش حقیقی پلن رایگان فقط پس از آزمایش روی گوشی مشخص می‌شود. این تغییر ادعایی درباره دسترسی همه حساب‌های رایگان به فصل فعلی ندارد.
