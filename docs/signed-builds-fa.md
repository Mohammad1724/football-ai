# نسخه امضاشده و به‌روزرسانی بدون حذف برنامه

## مشکل قبلی

هر بیلد در GitHub Actions با یک **کلید دیباگ تازه** امضا می‌شد؛ آن کلید روی هر ماشین
تازه ساخته می‌شد و از بیلد قبلی متفاوت بود. اندروید اجازه نمی‌دهد بسته‌ای با امضای
دیگر روی برنامه نصب‌شده برود، پس تنها راه نصب نسخه جدید، حذف برنامه بود — و حذف
برنامه یعنی پاک‌شدن پایگاه داده محلی و تاریخچه پیش‌بینی‌ها.

## کاری که انجام شد

1. یک **کلید ثابت** ساخته شد: `signing/footballai-release.p12` (RSA 4096، خودامضا،
   اعتبار ۳۰ سال). اثر انگشت گواهی:
   `7cd605244926555fa5e51be08601d89e908e6df474f10b592ecf71b35f73d668`
2. هر دو نوع بیلد (debug و release) با همین کلید امضا می‌شوند.
3. `versionCode` در CI برابر `۲۰ + شماره اجرا` است، پس هر بیلد از قبلی جدیدتر است و
   اندروید آن را «به‌روزرسانی» می‌شناسد، نه «نسخه قدیمی‌تر».
4. در CI یک گام **بررسی امضا** اضافه شد: اگر اثر انگشت گواهی با مقدار بالا یکی نباشد،
   بیلد شکست می‌خورد. یعنی امضا نمی‌تواند بی‌صدا عوض شود.
5. کوچک‌سازی کد (R8/shrink) در نسخه release **خاموش** است تا یک APK کوچک‌تر به قیمت
   خرابی احتمالی در دست شما نرسد؛ این محیط دستگاه تست ندارد.

## کاری که شما باید یک‌بار انجام دهید

برنامه‌ای که همین حالا نصب است با کلید قدیمی امضا شده است. پس:

1. برنامه فعلی را **یک‌بار** حذف کنید.
2. آخرین آرتیفکت `football-ai-signed-apk` را از صفحه اجرای GitHub Actions بگیرید
   (داخلش هم APK نسخه release هست و هم debug؛ پیشنهاد: release).
3. نصب کنید.

از این به بعد هر بیلد جدید را می‌توانید روی همان برنامه نصب کنید و داده‌ها
(تاریخچه، پیش‌بینی‌ها، تنظیمات) سر جای خودشان می‌مانند.

## هزینه این کار

کلید در مخزن عمومی است. یعنی هر کسی که به مخزن دسترسی دارد می‌تواند APKی بسازد که
اندروید آن را «به‌روزرسانی» همین برنامه بداند. برای نصب دستی از GitHub Actions
قابل قبول است؛ برای انتشار در Google Play قابل قبول نیست. اگر بعداً لازم شد، همین
کلید را می‌توان به GitHub Secrets منتقل کرد؛ فایل `app/build.gradle.kts` از قبل
متغیرهای `FOOTBALLAI_STORE_PASSWORD` و `FOOTBALLAI_KEY_ALIAS` را ترجیح می‌دهد.

## چیزی که تأیید نشده

نصب روی گوشی در این محیط ممکن نیست. امضا و اثر انگشت در CI بررسی می‌شود، اما
«نصب شد و به‌روزرسانی روی نسخه قبلی نشست» را فقط شما می‌توانید تأیید کنید.
